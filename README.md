# 雾港回声

一个以蒸汽悬疑为题材的中文文字冒险游戏项目。

项目以“记忆被偷走的城市”为核心概念，围绕钟塔旧案、失忆事件和晨星引擎展开叙事。玩家将扮演钟表修复师林澈，在列车、报社、医院、地下剧场与钟塔之间推进调查，并在不同选择下走向不同结局。

## 项目亮点

- 原创剧情体量约 `1.1w+` 字
- 多节点分支推进与 `4` 个不同结局
- 桌面端完整 UI，包含主菜单、剧情阅读区、状态面板与可滚动选项区
- 支持背景音乐播放与 Windows `exe` 打包
- 附带完整剧情梳理文档与 Mermaid 流程图

## 项目定位

这个项目既是一个可运行的桌面端文字冒险原型，也是一个完整的游戏策划与叙事设计展示项目，适合用于：

- 校招游戏策划作品集
- 叙事策划 / 剧情策划项目展示
- 文字冒险游戏原型验证

## 世界观概述

七年前，雾港钟塔发生爆炸，主角林澈的父亲林岐舟死于其中，官方说法是锅炉事故。

七年后，城里不断出现“断忆者”，他们会突然失去一部分记忆，像是有人偷走了他们的昨天。林澈因旧友沈砚的一封急信重返雾港，逐步发现钟塔旧案、晨星引擎与城市失忆事件之间存在直接联系。

玩家最终要面对的核心问题不是单纯“查出真相”，而是决定：

- 是否改造晨星引擎，让记忆归还众人
- 是否彻底毁掉它，阻止继续被利用
- 是否先公开真相，让城市自己面对后果

## 核心设计

### 1. 分支叙事

游戏从列车归乡开场，前期提供多种调查切入方式：

- 偷听线：偏侦查与洞察
- 直闯线：偏冲突与胆识
- 稳查线：偏协作与人心

不同选择会影响：

- 更早接触的角色与场景
- 获得的线索顺序
- 与沈砚、乔曼、陆庚等人的关系
- 最终结局的情感与逻辑走向

### 2. 属性倾向

游戏设计了三项基础倾向：

- `胆识`：更偏向正面突破与高风险推进
- `洞察`：更偏向观察、推理与信息整合
- `人心`：更偏向协作、信任与同伴关系

这三项不是传统数值战斗系统，而是服务于剧情风格与玩家体验差异化的叙事机制。

### 3. 终局收束

所有中期线索最终会汇合到钟塔核心阶段，并收束到四个主要结局：

- `回声归港`
- `静默之火`
- `把钟声交给众人`
- `断针`

## 技术实现

- `Python`
- `Tkinter`
- `PyInstaller`

当前版本为桌面端原型，支持打包为 Windows 单文件可执行程序。

## 本地运行

```powershell
python .\generate_bgm.py
python .\main.py
```

## 打包方式

```powershell
.\build.ps1
```

打包完成后，生成文件位于：

```text
.\dist\FogHarborEcho.exe
```
