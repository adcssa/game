# 雾港回声

一个以蒸汽悬疑为题材的中文文字冒险游戏项目。

项目以“记忆被偷走的城市”为核心概念，围绕钟塔旧案、失忆事件和晨星引擎展开叙事。玩家将扮演钟表修复师林澈，在列车、报社、医院、地下剧场与钟塔之间推进调查，并在不同选择下走向不同结局。

## 项目亮点

- 原创剧情体量约 `1.1w+` 字
- 多节点分支推进与 `4` 个不同结局
- 桌面端完整 UI，包含主菜单、剧情阅读区、状态面板与可滚动选项区
- 支持背景音乐播放与 Windows `exe` 打包
- 附带完整剧情梳理文档与 Mermaid 流程图

## 游戏下载

- Windows 可执行文件：[FogHarborEcho.exe](./dist/FogHarborEcho.exe)

## 世界观概述

七年前，雾港钟塔发生爆炸，主角林澈的父亲林岐舟死于其中，官方说法是锅炉事故。

七年后，城里不断出现“断忆者”，他们会突然失去一部分记忆，像是有人偷走了他们的昨天。林澈因旧友沈砚的一封急信重返雾港，逐步发现钟塔旧案、晨星引擎与失忆事件之间存在直接联系。

玩家最终要面对的核心问题不是单纯“查出真相”，而是决定：

- 是否改造晨星引擎，让记忆归还众人
- 是否彻底毁掉它，阻止继续被利用
- 是否先公开真相，让城市自己面对后果

## 安装与运行

### 方式一：直接运行可执行文件

如果已经拿到打包好的 `FogHarborEcho.exe`，双击即可运行，无需额外安装 Python 环境。

### 方式二：从源码运行

1. 安装 `Python 3.10+`
2. 下载或克隆本仓库
3. 在项目目录下执行：

```powershell
python .\generate_bgm.py
python .\main.py
```

### 打包为 exe

如果需要自行打包 Windows 可执行文件，可在项目目录下执行：

```powershell
.\build.ps1
```

打包完成后，生成文件位于：

```text
.\dist\FogHarborEcho.exe
```
